# STORM.EXE · Club Racing 03 更新说明

这次更新围绕「驾驶动作有原因、车辆反馈看得见、每一圈有改进依据」重做驾驶体验，并补齐赛事、操控、训练、记录、回放与声音。保留 Rocky Pass 赛道和四辆赛车。

本作定位为浏览器端的偏拟真街机驾驶。车辆动力、轮胎、空气动力与底盘参数均为游戏调校数据，未经过厂家或实车标定；下列升级不代表与商业顶级赛车游戏具有相同的物理精度。

## 驾驶手感的核心升级

- **前后轴分别产生轮胎力。** 车身朝向与实际运动方向分别计算，侧滑角与横摆惯性参与入弯、收油、推头和甩尾，车辆不会因为转动方向而立即改变全部运动速度。
- **刹车与转弯共享抓地能力。** 前后轴使用组合抓地预算，重刹时留给转弯的余量会减少；纵向载荷转移、速度相关下压力和湿地抓地变化共同影响车辆响应。
- **转向随车速变化，允许反打救车。** 转向有输入、回正与反打响应；高速限制过量转角，发生真实侧滑时增加反打可用转角，帮助接住手刹甩尾。
- **油门和刹车渐进响应。** 加入收油发动机制动、换挡动力中断与后轴手刹；油门和刹车同时输入时优先制动。刹停后继续保持刹车约 0.45 秒才选择倒挡。
- **四款赛车使用独立调校。** 动力、轴距、前后轴配重、轮胎侧偏刚度、制动分配、空气动力与齿比存在差异。AI 和玩家使用同一套车辆模型与碰撞系统。
- **三档驾驶辅助。** 「轻松」「运动」「专家」调整稳定辅助、牵引力控制、ABS 和转向响应；专家模式关闭 ABS 与牵引力控制，仍保留很少的稳定辅助。
- **变速箱与遥测来自物理状态。** 自动换挡带升降挡迟滞，输出真实的游戏内挡位、转速、踏板、侧滑、横向及纵向加速度，供仪表与音效共同使用。
- **固定物理步长。** 按 120 Hz 子步积分，30、60、120 Hz 调用经过同一套积分过程；继续保留连续墙体碰撞和桥面支撑保护。
